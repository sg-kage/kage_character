# カゲマスキャラ検索DB

**陰の実力者になりたくて！マスターオブガーデン（カゲマス）** のキャラクター性能検索ツールです。

公開URL: https://sg-kage.github.io/kage_character/

## 機能

- キャラクター名・スキル効果・魔道具などのキーワード検索（`-語` で除外も可能）
- 検索中は、語が書かれている項目（奥義・特技・特殊・コンボ・通常・魔道具）を一覧の各行にタグで表示（タグを押すと詳細のその場所へ移動）
- 属性・ロール・グループ・効果名によるフィルタリング（効果は対象＝自分/味方/敵でも絞り込み可能）
- 好感度Lv / 魔道具Lv に応じたスキル数値のリアルタイム計算
- 覚醒前後のスキル比較表示、2体比較
- キャラクター詳細の最後に「似た性能のキャラ」を表示（効果の重なりで判定。押すとそのキャラを開く）
- 前回の訪問以降に追加されたキャラに NEW を表示（7日間）、追加時は画面下にお知らせ
- キャラクター詳細のスクリーンショット生成（PNG保存）
- URLパラメータによるキャラクター共有（`?pos=ポジション番号`、2体比較中は `&cmp=ポジション番号` も付与され比較状態ごと共有可能）
- フィルタ・検索条件もURLに反映されるため、絞り込み結果ごと共有可能
- 日本語 / English / 繁體中文 の言語切替（ヘッダー右上）
- PWA対応（ホーム画面に追加可能・一度表示したページはオフラインでも閲覧可能）

### 検索コマンド

キーワードの前に項目名をつけると、その項目だけを絞り込めます。先頭に `-` をつけた語は、その語を含むキャラを除外します（項目名と組み合わせ可能）。

```
特殊:シールド      → 特殊にシールドを含むキャラ
魔道具:パリィ      → 魔道具にパリィを含むキャラ
奥義:〇〇          → 奥義に〇〇を含むキャラ
特技:〇〇          → 特技1/特技2に〇〇を含むキャラ
コンボ:〇〇        → コンボに〇〇を含むキャラ
通常:〇〇          → 通常攻撃に〇〇を含むキャラ
シールド -シャドウ  → シールドを含み、シャドウを含まないキャラ
-魔道具:パリィ     → 魔道具にパリィを含まないキャラ
```

## 多言語対応（i18n）

UI文言とキャラデータを**ロケール別ファイル**に分離した構成です。対応言語は日本語（`ja`、既定）・英語（`en`）・繁体字（`tw`）で、ヘッダー右上のセレクトまたは `?lang=en` / `?lang=tw` で切り替えられます（未訳キーは自動的に日本語へフォールバック）。UI文言・キャラデータとも3言語分あります。en / tw のキャラデータは AI 翻訳のため、画面に注意書きを出しています。

### 言語を1つ追加する手順

`<locale>` を ISO コード（例: `en`）として:

1. **UI文言**: `i18n/<locale>.json` を作成（`i18n/ja.json` と同じキー構造）。空文字のキーは `ja` にフォールバックするため、訳せたものから埋めればよい。`js/i18n.js` の `SUPPORTED` 配列に `<locale>` を追加する。
2. **キャラデータ**: `characters/all_characters_<locale>.bin` と `characters/update_date_<locale>.json` を配置（生成スクリプト側で `_<locale>` 名で出力する）。無い場合は `_ja` に自動フォールバックする。
3. `index.html` の `#lang-select` に `<option value="<locale>">言語名</option>` を追加する（切替は `I18N.setLocale()` が処理）。

### 翻訳しない文言について

属性（赤/緑/黄/青）・ロール・ガチャ・レア度などの**データ値**は、UIリソースではなく**キャラデータファイル側**で翻訳する想定。これらはフィルタ判定のキーにも使われるため、ボタン表示とデータ値が一致している必要があるため。

> 注: 固定enum値（属性/ロール/ガチャ/レア度）のボタン表示は、内部値（日本語）を保持したまま i18n の `data.*` マップで表示のみ変換する方式で言語化済み。フィルタ判定・URLパラメータは常に日本語の正規値を使う。

## キャラクターデータの更新

`characters/all_characters_<locale>.bin` は生成スクリプトで出力したものを配置します（直接編集しません）。

### データ構造

```json
{
  "CharacterID": 0,
  "name": "キャラ名[コスチューム名]",
  "attribute": "赤|緑|黄|青",
  "role": "アタッカー|タンク|サポーター",
  "position": 100,
  "arousal": "覚醒順序の説明",
  "group": ["グループ名"],
  "aliases": "別名,検索用キーワード",
  "ultimate": [{"title": "奥義名", "normal": "覚醒前説明", "awakened": "覚醒後説明"}],
  "ex_ultimate": [],
  "skill1": [{"title": "特技名", "normal": "...", "awakened": "..."}],
  "skill2": [{"title": "特技名", "normal": "...", "awakened": "..."}],
  "traits": [{"title": "特性名", "normal": "...", "awakened": "..."}],
  "combo": "コンボ説明",
  "normal_attack": "通常攻撃説明",
  "magic_item1": [{"title": "魔道具名", "normal": "..."}],
  "magic_item2": [{"title": "魔道具名", "normal": "..."}]
}
```

> 注: `CharacterID` は配列内の並び順（0始まりの連番）で、データを並び替えると値が変わります。
> 個体を安定して指し示すキー（お気に入り保存・URL共有など）には、ゲーム内で一意な `position` を使用してください。

### 変動値の書き方

レベルによって変化する数値は `{最小値, 最大値}` の形式で記述します。

```
「威力{100.00, 200.00}%」
→ Lv1 で 100%、Lv10（または∞）で 200% として表示されます
```
